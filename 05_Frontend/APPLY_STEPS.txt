Issuer Management reuses the existing ADMIN endpoints:
- GET /api/v1/admin/users?role=ISSUER
- GET /api/v1/admin/users/{userId}
- PUT /api/v1/admin/users/{userId}/status

The institution association is deliberately read-only. This module does not create issuer accounts,
change institution assignments, generate keys, or alter existing RSA key material.
